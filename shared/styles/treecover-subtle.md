# Treecover subtle

**Layer kind**: tree-cover percentage raster (EarthEnv / NALCMS woodland tint)
**First used**: rainfall (`woodland_treecover.tif`); recalled for sky-islands (2026-08-28)

## Recipe
1. Apply the saved ArcGIS Pro style named **Treecover subtle**.
2. Set layer transparency to **85%**.

## Draw order
Above the hillshade.

## Notes
Intended as a faint green wash over relief, not a readable data layer.
