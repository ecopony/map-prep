# Style library

ArcGIS Pro symbology recipes, in words, so a layer treatment from one map can be repeated in the next. Managed by the `style` skill (`save "<Name>, <recipe>"` / `retrieve <name> style`). One file per style; index below, alphabetical.

- [Treecover subtle](treecover-subtle.md) — saved Pro style of the same name, 85% transparent, above hillshade
